# Abitna Recorder — Rilis Resmi

Repo ini digunakan untuk mendistribusikan file executable **Abitna CCTV Recorder**. Source code aplikasi tidak disimpan di repo ini.

## Download

Unduh file `abitna-recorder.exe` dari bagian **Assets** pada [rilis terbaru](https://github.com/Bayuset12/abitna-recorder-releases/releases/latest).

## Persyaratan

- Windows 10/11 atau Windows Server.
- Koneksi internet diperlukan untuk memeriksa dan mengunduh update.

## Instalasi dan menjalankan

1. Unduh `abitna-recorder.exe` dari Assets rilis.
2. Simpan file tersebut di folder aplikasi.
3. Jalankan `abitna-recorder.exe`.

Simpan konfigurasi, lisensi, dan data aplikasi sesuai pengaturan instalasi Anda. Jangan menghapus atau mengganti file konfigurasi saat memperbarui aplikasi.

## Memperbarui aplikasi

1. Unduh `abitna-recorder.exe` dari rilis terbaru.
2. Hentikan aplikasi atau Windows Service Abitna Recorder.
3. Ganti executable lama dengan file yang baru diunduh.
4. Jalankan kembali aplikasi atau Windows Service.

Update yang diunduh tidak dipasang otomatis. Pastikan aplikasi/service sudah dihentikan sebelum mengganti executable.

Mulai versi **1.0.1**, pemeriksaan update tersedia di **Settings → Update → Check for Update**.

## Catatan rilis

Setiap rilis berisi nomor versi dan catatan perubahan. Pastikan tag versi dan nomor versi aplikasi sesuai sebelum mengunduh atau memasang rilis.
